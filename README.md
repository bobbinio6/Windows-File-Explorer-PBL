# Windows File Explorer PBL Project

**Course:** Data Structures and Programming in C++ (DSCPP)  
**Project Title:** User-Friendly File System Explorer  
**Programming Language:** C++

## 1. Project Description

This project aims to develop a user-friendly Windows File Explorer using C++ and the Win32 API. The application will allow users to navigate folders, view files and directories, and perform common file-management operations through a graphical user interface.

The project applies fundamental data structures and C++ programming concepts to organize and manage file information. It demonstrates the practical use of tree structures, vectors, stacks, searching, traversal, and object-oriented programming in developing a desktop file-management application.

## 2. Project Objectives

1. Develop a graphical Windows File Explorer using C++.
2. Apply tree data structures to represent hierarchical folders and subfolders.
3. Use appropriate data structures to organize and manage file information.
4. Implement searching and traversal operations.
5. Apply object-oriented programming concepts.
6. Support common file operations such as creating, copying, moving, renaming, and deleting files.
7. Demonstrate the practical application of Data Structures and C++ programming.

## 3. Data Structures and Concepts

- **Tree:** Representing hierarchical folder and subfolder structures.
- **Vectors:** Organizing and storing directory contents.
- **Stacks:** Managing navigation history.
- **Searching:** Finding files and folders.
- **Traversal:** Visiting and exploring directory structures.
- **Object-Oriented Programming:** Using classes, objects, encapsulation, and functions.

## 4. Technologies Used
